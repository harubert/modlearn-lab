1. Die Fakten

Der Tutor läuft auf dem offenen Sprachmodell {{ spark.0 }}{% if spark.1 %} des Unternehmens {{ spark.1 }} ({{ spark.2 }}){% endif %}, auf einem Rechner der Pädagogischen Hochschule Vorarlberg. Offene Sprachmodelle aus China antworten auf Fragen, die der chinesischen Regierung unangenehm sind, ausweichend oder in deren Sichtweise. Das ist in der Forschung dokumentiert{% if spark.2 == "China" %}, und es betrifft das Modell, das hier arbeitet{% endif %}. Wir prüfen es an unserem Modell selbst, mit zwölf Fragenpaaren an vier Stellen; die Zahlen stehen unten.

2. Darum geht es hier nicht

Der Tutor unterrichtet Mathematik, Deutsch, Englisch, Sachunterricht und Musik. Er ist keine Auskunftsstelle und keine Suchmaschine. Was nicht zur Stunde gehört, beantwortet die Anwendung mit demselben Satz, ob die Frage Peking oder Berlin betrifft. Das erzwingt der Server, nicht das Modell: Vor jeder Antwort entscheidet ein Pförtner nur eines, nämlich ob der Beitrag zur Stunde gehört. {% if pfoertner %} Das ist {{ pfoertner.0 }}{% if pfoertner.1 %} von {{ pfoertner.1 }} ({{ pfoertner.2 }}){% endif %}, ein zweites Modell, das nie für die Kinder schreibt. {% else %} Derzeit urteilt dafür das Sprachmodell selbst; ein zweites Modell für dieses Urteil ist vorgesehen, sobald die Prüfung zeigt, dass es gebraucht wird. {% endif %} Sagt der Pförtner nein, schreibt kein Modell die Antwort.

3. Was wir tun

Im Safe Chat, wo Kinder frei fragen dürfen, prüft die Anwendung jede Antwort auf die Form einer Verweigerung („in China als sensibel eingestuft“, „gegen gesetzliche Bestimmungen“). Trifft sie, erreicht der Wortlaut das Kind nicht: Es liest, dass die KI am Spark ausweicht, und kann die Frage, wenn die Lehrperson es freigegeben hat, durch den Filter nach draußen schicken. Jede Antwort trägt den Namen des Modells, das sie geschrieben hat.

Und wir messen. Zwölf Fragenpaare: links eine Frage, an der ein chinesisches Modell hängen könnte, rechts eine ebenso heikle Vergleichsfrage, die ein westliches Modell frei beantwortet. Jedes Paar wird dem Modell ohne Anweisung gestellt, in einer Mathematikstunde, im Sachunterricht und im Safe Chat. Gezählt wird zweimal: Die Anwendung zählt die Form der Antwort, automatisch. Und ein zweites Modell liest jede Antwort und beurteilt den Inhalt, denn die Form allein täuscht: Ein Modell kann antworten und dabei nur die Sicht einer Regierung wiedergeben, oder in einem freundlichen Satz verweigern.

4. Einordnung

Kein Sprachmodell ist neutral. Amerikanische Modelle tragen die Prägung ihrer Hersteller und ihrer Rechtsordnung, europäische ebenso. Der Unterschied ist, dass wir die Prägung unseres Modells kennen, benennen und messen. Für das Rechnen, Lesen und Sprechen mit Kindern ist {{ spark.0 }} derzeit eines der besten offenen Modelle, das auf unserem Rechner läuft; und es lässt sich austauschen, ohne dass sich für die Kinder etwas ändert. Diese Seite sagt dann, welches Modell an seine Stelle getreten ist.

Fragen dazu beantwortet das ModLearn Technology Lab der PH Vorarlberg. Was die Anwendung speichert und was nicht, steht in der Datenschutzerklärung.
